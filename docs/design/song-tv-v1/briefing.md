# 今日：宋式家庭简报

2026-09-12，实施设计。页面代码 `b025b17` 已完成审查和三尺寸浏览器验证，并随干净 `28ffc09` 部署到家庭设备；OnePlus 全遥控与 AI 回归通过，真实电视仍待验收。范围是用户确认的家庭今日概览：日程、家庭提示、房屋状态。首批仅接已可用的提示和中枢状态，日历来源仍待明确。契约见 [简报实施计划](../../plans/2026-09-12-briefing-foundation.md)。

## 视觉与内容

延续纸白、青瓷、墨色及本地宋体标题/黑体正文，像一张放在客厅的日用笺：左边读事项，右边辨来源。沿用现有 token、Masthead 与导航，避免另建一套卡片仪表盘。首页的照片主体保持；“今日”成为明确的导航入口。

导航次序为“首页、照片、今日、房屋、设置”。标题“今日”配家庭时区日期。主体约三分之二宽为事项，右侧三分之一为来源摘要，底部固定刷新按钮和操作提示。短视口收起重复 Masthead、减少间距，保留正文字号。长内容只在主体内部滚动，来源摘要不随事项滚走。

事项按契约顺序呈现：需要关注的来源状态在前，有效家庭提示随后。每项有短标题、来源名称和适用的观测/有效时间，不把“最近检查”标为“内容更新”。来源过期时优先写“状态待更新”，旧健康结论只能作为上次观测。失败文案不显示路径、内部错误或诊断参数。

侧栏列出家庭日历、家庭提示、中枢来源、房屋资料与环境数据的接入情况；来源多时归纳为数量和状态分布，并提供“查看房屋”进入现有详情页，不靠截断隐藏异常。不得因未连接日历显示“今天没有安排”。没有有效提示与异常引用时，主体写“当前没有可展示的提示”，侧栏继续保留未连接/待更新信息，不输出“家里一切正常”。

提示正文可换行完整阅读。第一屏应显示至少一项标题、来源、状态与部分正文；长文不撑开页面，不使用自动滚动或跑马灯。没有示例家庭事项、假温湿度、不可操作的日历按钮。日历接入后的议程样式另补，不预先伪造事件。

## 遥控焦点

首次进入聚焦事项阅读区；无事项时聚焦空状态区域，同样可以继续进入按钮。阅读区是可滚动区域，不给每段文字创建按钮。

| 位置 | 按键 | 行为 |
| --- | --- | --- |
| 阅读区 | 上/下 | 分段滚动；到底后下移至刷新 |
| 阅读区 | 右 | 进入“查看房屋” |
| 阅读区 | 左 | 进入导航“今日” |
| 查看房屋 | 确认 | 打开房屋页，返回时恢复本按钮 |
| 查看房屋 | 左/上 | 回阅读区 |
| 查看房屋 | 下 | 进入刷新 |
| 刷新 | 确认 | 重取 overview，保留焦点并反馈结果 |
| 刷新 | 上 | 回阅读区 |
| 刷新 | 下 | 进入导航“今日” |
| 导航 | 左/右 | 顺序移动，边缘停留 |
| 导航 | 上 | 回阅读区 |
| 任意区域 | 返回 | 沿既有返回栈返回来源页和入口焦点 |

来源更新、条目到期与远程 refresh 均不跳页。移除内容后保留可用焦点，滚动限制在新的有效范围。简报 → 房屋/照片/设置 → 返回必须恢复所用入口；一次 Back 只消费一层。鼠标点击与确认执行相同动作。

## 时间、失败与授权

页面可见时每 30 秒重取，进入/回前台/重连及相关通知立即重取，后台停止周期请求。根据服务端校时在提示截止时撤下内容，离线也不延长有效区间；刷新失败保留仍有授权且未到期内容，并明确标为旧数据。客户端重算来源状态和事项顺序，在线来源过期也会出现“状态待更新”；旧异常到期不再按当前已确认异常呈现。未下发的未来提示由下一次可见页面轮询发现，不承诺在开始秒数精确出现；不得提前展示。服务端返回失败空投影、成功空列表或移除来源时立即替换旧内容。

简报独立于照片接口。沿现有连接页“查看中枢状态”真实鉴权进入房屋后，能从导航打开今日；不得绕过配对、授权过期和 superseded 单会话限制。简报处于可见路由时，照片 /home 失败不能强制遮住它。

新状态使用 AbortSignal、请求序号、授权代次、同步清空，与 House 同等处理 HTTP 401/410 screen_revoked、WS 4002、重新配对和 Core 切换。所有内容只在内存，不写浏览器持久缓存。新增本地 briefing 路由及上报枚举，远程 navigate 白名单仍仅 dashboard/photos。

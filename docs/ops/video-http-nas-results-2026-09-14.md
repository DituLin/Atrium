# NAS 视频内容接口验证

日期：2026-09-14。代码基线 `177f69c`，使用独立 loopback HTTP 服务和新建的隔离数据库、封面缓存。生产 Core、配置与数据库未修改；NAS 只读。

## 方法与结果

从既有授权根 `/Volumes/home/Photos` 选取先前的 12 个样本，重新经来源身份确认、视频观察、真实 ffprobe/ffmpeg 与 Worker 发布。12 个样本全部 ready，12 个封面共 461,495 字节。

每个样本请求首段、中段、尾段，各 256 KiB。36 次请求均返回 206，合计 9,437,184 字节，逐字节与来源文件的相同区段一致。请求携带仅在隔离数据库签发的一次性管理员凭据；凭据仅存在于测试进程内存，没有写入日志或代码。

请求耗时为 3–4 ms。这不是冷读吞吐或长期延迟指标：为了进行字节比对，测试先读取了源文件的相同区段，且服务与客户端同在 Mac mini，系统缓存可能参与。此次结果证明真实 NAS 样本经过实际 API、授权检查与 Range 路径能返回正确字节，不能替代 OnePlus/WebView、TLS、声音听感、持续播放与正式电视验收。

# 宋式照片版 · 首轮设计规范

2026-09-12 · T02/T03 实现基线。交付范围为设计与本地可操作原型；未改动生产 TV、Core、Android 或真实设备。纸白青瓷作为可调整的实现基线；用户视觉偏好问题已提出，尚未收到确认，不记录为用户已批准。原型完成不代表 M2 完成。

入口：[可操作原型](prototype.html) · [评审记录](review.md) · [既有设计讨论](../../plans/2026-09-06-song-tv-experience-design.md)。

## 范围与工作默认

已确认：宋式美学、TV 公共显示、遥控器优先、照片选择/预览/切换。此轮工作默认采用纸白与青瓷、照片约 2/3 / 时钟约 1/3 的不对称首页；原型提供墨夜首页对照。主题只做评审比较，不承诺生产自动昼夜主题。

首轮产品导航只有「首页 · 照片 · 设置」。六类画面为首页、集合/图库、单图、连接/配对、设置/状态、加载/空/错误。简报/房屋/日历/视频在产品画面之外的评审工具中显示后续设计说明，不是本轮产品入口。

家中传感器、房间资料、日历来源、公开字段、视频格式与样本均未确定。本原型没有伪造家庭日程或环境读数。所有图片、日期、时间、屏幕名、连接状态和配对码都明确为示例。

原型的设计尺度以产品区域的宽/1920、高/1080 的较小者缩放。1920×1080、3840×2160、804×384 是**浏览器整体 CSS 视口**，顶部 48px（小屏 36px）的评审工具占用额外空间，因此实际产品区域更矮，不能把原型缩放值当作生产 CSS 像素。高 DPI 小视口需单独检验；真实电视上 2–3 米阅读仍是独立验收。

首页采用装裱式素色画幅与少量题签，不给原图套滤镜。图库缩略图固定 4:3，允许裁切；单图始终 `object-fit: contain`，竖图与全景保留原比例和边缘。超长标题在图库单行省略，进入单图操作层可阅读完整标题。日期缺失显示「拍摄时间未知」，不推断拍摄地点或事件。

## 遥控器与返回栈

点击与按键均调用同一动作 dispatcher。浏览器评审控件使用原生鼠标/键盘，操作后产品焦点按场景规则恢复。

| 输入 / 场景 | 规则 |
| --- | --- |
| 方向键 | 移动焦点；到行边缘停住，不自动环绕，不因获得焦点切路由 |
| Enter / 点击当前照片 | 首页一次确认直接进入单图；没有多一次「唤醒」 |
| 首页初始焦点 | 当前照片。向下到首页导航，向右到状态；状态向左回照片，向下到设置导航 |
| 导航 | 左右在首页/照片/设置间选中焦点；确认才进入；向上回当前页面主区 |
| 图库集合 | 左右换焦点，确认应用集合并进入首图；未确认时向下进入当前集合首图 |
| 网格 | 实时读取 CSS 网格列数（桌面 4、小 CSS 视口 3）；上下按实际列移动；顶行上返集合，末行下返照片导航；上方短尾行没有同列候选时向下停留 |
| 单图左右 | 当前进入时序列的前后张；边缘停住；不重复请求随机接口来寻找相邻图片 |
| 单图 Enter | 显示操作层，焦点在「关闭操作」；操作层左右选按钮，确认执行；「关闭操作」关闭层 |
| Escape / Backspace | 单图先关闭操作层，下一次返回来源页；恢复来源集合、卡片与滚动位置 |
| 首页返回 | 导航/状态先回当前照片；当前照片处出现继续使用/退出演示菜单；菜单不调用设备退出 |
| 快速重复 Enter / Back | 忽略键盘 repeat，避免同一个按住事件穿透多个层级；方向键可连续移动 |
| 系统 Home | 不拦截、不模拟原生系统键 |
| 状态更新 | NAS/连接更新在当前路由显示说明，不自动开详情/弹窗，不变更产品焦点 |

原型「开始轮播」仅展示明确的手动/轮播状态切换，不设置自动切图定时器。生产需保留显式 `show` 暂停并保持单图、`refresh` 保持页面、当前 generation 加载后才确认的语义；本原型不实现、不发送、不确认任何 Core/MCP/TV 命令。

图库与设置返回恢复来源入口；设置侧栏提供连接状态、照片来源、关于 Atrium 三项，确认切换内容，向右进入操作。图库四类集合：最近新增（首次发现）、今天拍摄、随心看看（本次固定示例顺序）、全部照片。首页进入使用本地已知稳定序列，图库进入使用该集合当前序列。生产随机 API 是否能提供稳定邻居仍是 T06 客户端设计问题。

## 瞬态、缺来源与错误

| 评审场景 | 展示与恢复规则 |
| --- | --- |
| 正在读取照片 | 独立加载页，示例「模拟完成」动作；不凭真实计时假装请求成功 |
| 暂无照片 | 说明当前集合为空；「查看全部照片」和「查看状态」 |
| NAS 暂不可用 | 当前内容保留，只有仍授权、确实可用的照片才可在真实系统继续展示；状态页反映来源异常 |
| 连接断开 | 保留页面与焦点；显示上次可用内容、新内容和控制暂不可用；不假装 NAS 同时离线 |
| 单图加载失败 | 选择场景后首次向右显示失败，当前图保留；再次向右继续浏览示例序列。属于故障恢复动作草稿，不是网络模拟 |
| 授权已失效 | 清除当前查看序列与返回栈，进入独立错误页并停止展示照片；导航、返回、直接单图场景均不能恢复照片，只有明确「模拟配对完成」恢复示例授权。生产授权时限不在此原型里执行 |
| 证书验证失败 | 独立错误页，重试仍显示错误与维护端说明；没有跳过证书验证入口 |
| 资源移除 | 从单图返回来源，图库选择相邻有效卡片并解释；为了可重复评审，示例列表不实际删除素材 |
| 成功空数据 / 未连接 / 过期 / 同步失败 | 后续简报与日历必须分开，尚无真实来源时不能写「今天没有安排」或「家里正常」 |

设置/状态只演示 Core、NAS、屏幕、检查时间与版本。中枢健康不是房屋环境状态。连接页展示虚构配对码，不访问网络、不存凭据。原型不依赖服务端，直接打开本地 HTML 即可；所有资产本地供应。

## T07 生产返回约定（待实现验收）

原型的退出演示按钮不直接移植成网页退出权限。Android 容器按一次 Back 的处理结果决定是否显示现有原生菜单：

1. 单图操作层打开时先关闭操作层；下一次返回来源页与原入口。
2. 图库和设置返回来源入口；首页导航或状态处返回当前照片。
3. 已在首页照片处，网页不再消费 Back，原生容器才显示“继续展示 / 连接设置 / 退出应用”。浏览器单独运行时没有原生退出动作。

网页通过可取消键盘事件表示本次是否已处理，原生只读取这个结果；不提供任意网页调用原生功能的通用接口。移除按两次返回的时间猜测，避免快速连按穿过网页和原生两个层级。连续方向键保留，确认与返回的按住重复事件只消费一次；系统 Home 继续由 Android 处理。

原生异步回调需确认仍是当前 WebView、当前前台页面且没有其他原生覆盖层，防止旧页面的结果迟到后打开菜单。TLS 失败仍取消加载，重试必须重新验证证书。此约定要通过 Web 行为测试和 OnePlus 实机验证后才能记为完成。

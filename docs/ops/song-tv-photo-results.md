## T06 图库与单图往返

图库按同一个列数来源渲染与移动焦点：常规视口 4 列、小视口 3 列；首行返回合集、末行进入导航，短尾行没有同列候选时停留。进入预览时固定客户端已知照片顺序，首页使用本次已知轮播序列，图库使用当前合集已载入序列；不会反复查询随机邻居。浏览为手动模式，操作层默认聚焦“关闭操作”，Back 先关操作再回来源。当前 API 没有照片标题字段，因此不凭文件名编造题名。

返回记录包含来源卡片 ID、索引和滚动位置。刷新先原子重建已载入的页窗口；若插入或重排使原卡片落到本次有限窗口之外，保留原窗口并明确提示，不能把“第一页没看到”写成“照片已移除”。已确认失效或完整结果中移除的照片返回相邻有效卡片。

失败图片保留本次手动浏览中上一张已解码画面，并提供明确跳过/返回反馈；生成中的预览按既有间隔重试。相邻预取至多两张；预取和保留画面不提供命令的显示确认。新 show 清空旧浏览序列和保留画面，仍等待当前 generation 的真正图片 onLoad。授权失效清空新增加的浏览内容与返回记录。

## 测量脚本修正

旧 `bench-commands.sh` 使用 GNU `date` 的 `%N`，本机 BSD date 输出字面 `N`，可将真实亚秒耗时截断为 0；旧脚本还会在全部失败时以退出码 0 结束。此次用离线假 CLI 复现后修复，三个回归用例先失败后通过，独立审查接受。

新版 Python 3 单调时钟覆盖 CLI 启动至终态回执，包含请求和 250 ms 轮询开销，是控制延迟的保守上界。每个尝试保留状态、错误码及耗时，不重试；失败/未知样本阻止判定通过，失败样本不混作成功延迟。原始 JSONL 与摘要都禁止覆盖既有文件。超过上界目标时须进一步测量，不能直接归因于 Core 或 TV。

# 成长趋势看板

[English](growth-dashboard.en.md) · [文档索引](../README.md)

在 TV 的 **档案** 页面选择具体家人，在“全部领域”或“健康”下查看成长趋势。身高和体重分别展示最新测量、单位、日期、曲线及最近三次测量。看板适用于已归属的人物，不需要另建固定名单。

- 时间范围：近 3 个日历月、近 1 年、全部阶段；默认全部阶段。
- 横轴按实际测量日期间隔排列；纵轴显示数值刻度和单位。身高与体重使用各自尺度。
- 通过已有 IM 或档案接收流程提交日期、数值和单位明确的测量；已归属且获准 TV 展示的记录会随档案核验自动更新。支持 `height`、身高、身长以及 `weight`、体重字段。
- 不同单位和样本分别展示，不在浏览器换算、相加或混为一条曲线。精确测量值保持原记录的小数字符串。
- 不明确的日期、单位或数值不会补成测量点；待确认资料、超出统计范围和暂不可用状态会明确提示。较短范围可用于缩小过大的查询。
- 当前人物公开接口不提供可核验的出生日期，因此使用日期轴。不会从名字或发送者推断月龄，也不会绕过身份字段的展示权限。月龄／年龄标注需要后续接通经过授权的已确认出生日期。

遥控器左右键切换时间范围按钮，确认键应用范围；右侧边界进入内容阅读区，上下键可浏览内容。奶量（日／周／月）和其他现有档案曲线也提供 X、Y 轴刻度。

曲线展示已有测量历史，不生成未来身高、体重预测或医学百分位判断。看板数据覆盖全部授权查询结果，不受当前档案卡片分页影响。

# TV 深色界面实施计划

**目标**：按 2026-10-20 提供的六份 HTML 视觉稿更新现有 TV 前端。

**架构**：继续使用 React 页面、API 与遥控器焦点模型。全局深色设计变量和公共组件负责字体、颜色与导航；页面 CSS 负责布局。设计稿仅作为视觉参考，不引入脚本、远程字体或示例家庭数据。

**技术栈**：React 18、TypeScript、CSS、SVG、Vitest、Playwright；Chrome 66 基线。

1. 全局变量：背景 #0c0e0d、卡片 #171a19、焦点 #262b29，统一系统无衬线、数字等宽；顶部胶囊导航与圆角按钮。
2. 首页：保留常驻照片与菜单逻辑；实现 224u 时钟、胶囊提示、六张圆角菜单卡及毛玻璃不透明降级。
3. 影像：标题与排序提升到页面标题行；320u 合集侧栏、图标、圆角缩略图；保留照片/视频 API、分页和返回焦点。
4. 今日、房屋、设置：按稿子列宽与卡片布局改样式；万年历使用实时家庭日期；未接入内容保持诚实空状态。
5. 档案：深色侧栏、统计卡、最近档案；趋势用单调三次曲线、渐变与末点高亮；保留精确值、缺失数据和权限边界。
6. 验证：已有前端测试基线；新增曲线边界验证；全套 test、lint、build；合成 mock 下六页遥控操作和 1920×1080 / 804×384 浏览器检查。实际 TCL TV 验证另列为待完成，不将浏览器模拟视作实机证据。

不添加稿子中无现有数据契约的房屋曲线和虚构统计；保留现有功能和错误反馈。公开文档如有变更需同步中文与英文。

## 实施与验证记录

- 已完成六页深色公共视觉、胶囊导航、首页菜单、影像标题与图标侧栏、信息页卡片和档案领域胶囊。
- 趋势图使用保形三次曲线、渐变填充与末点高亮；不改变 Core 精确数值与权限判断。
- 修复领域胶囊移动后遥控不可达的问题，并新增回归测试；将既有奶量测试的日期固定在合成观测所属范围内，避免随运行日期失效。
- 最终完整前端测试 486 项通过（69 个测试文件）。lint、生产构建和 Chrome 66 CSS 构建检查通过。
- 1920×1080、804×384 Chromium 合成数据截图检查：六页无页面错误，页面不越出可视区域。非 16:9 视口画布等比居中。
- 保留实现边界：照片网格沿用现有 4 / 3 列；房屋 profile/environment API 尚无结构化条目，不添加示例曲线；档案图表保留当前 API 分组与精确明细，不编造奶量构成、支出或样本数据；万年历沿用已验证的节气日期，无示例进度数字。
- 尚未部署，也未进行真实 TCL TV 的视觉、性能或视频解码复验。历史实机验证不等于本轮改造已获实机验收。

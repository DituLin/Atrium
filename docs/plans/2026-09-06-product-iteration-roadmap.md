# Atrium：从三端验证进入产品迭代

日期：2026-09-06。依据 PRD v0.1、现有代码、G0 记录与同日 Android TV 实测。本文是需求差距审计与建议路线，视觉方案尚未定稿。

后续讨论已明确采用宋式美学，并将视频、简报、房屋信息与日历纳入产品设计范围。最新设计讨论由 [TV 视觉与交互设计](2026-09-06-song-tv-experience-design.md) 承载；本文保留原 PRD 的差距审计，不能将下述原首期排除项理解为禁止讨论新增需求。

最新优先级：先完成 [AI Brain 与 home-mcp 技术方案](../tech/2026-09/atrium-home-hub/ai-brain-home-mcp-design.md)，TV 视觉方案保留、实现暂后置。下述四轮产品路线作为后续规划，不代表当前立即执行顺序。

## 当前结论与范围

用户将第一版定位为 Mac mini（Core）、群晖 NAS（照片）、TV（公共显示）三端链路验证。该链路已在 OnePlus 6T 作为 TV 测试终端的条件下跑通：真实照片、安全连接、独立 Android 应用、遥控按键、服务端控制、断线恢复。真实电视兼容性仍未验收。

原 PRD 的 V0.1–V0.3 本身就是技术基础版，并未定义完整的 TV 视觉设计稿。18 个 FR 中 16 项为 P0、2 项为 P1；16 项 P0 均有对应实现，不等于 16 项已经全部通过正式验收。不能把“代码覆盖率”当作产品完成百分比。

用户当前明确：优先继续 Atrium 功能及 Android TV 视觉/交互迭代；Mac 断电恢复和 NAS 自动挂载暂停，不进入以下产品迭代。原 PRD 的正式 V1 发布门槛仍保留，暂停项不标记通过。

## 下一阶段：4 轮产品工作

### 第 1 轮：TV 设计与可操作原型（最高优先）

交付 6 类界面：常驻首页、集合选择/图库、单张照片、连接/配对、设备设置/状态、加载/空/错误状态。后两项中的设置信息架构为新增产品设计范围，现有原生设置仅提供基础连接与退出。

交付统一设计规范：色彩、中文字体层级、间距、安全边距、图片比例、焦点样式、动效、状态文案；以 1920×1080 为设计基准，检查 4K 与 OnePlus 的高 DPI、小 CSS 视口。

原型必须支持方向键/确认/返回，明确初始焦点、边界行为、区域切换、列表滚动和返回位置。静态画面好看不作为遥控验收通过。

候选方向：

1. **家庭相框 + 轻信息（建议）**：照片占主要面积，时间日期安静呈现；操作时显示入口和提示，正常状态简洁可见，故障显示明确文字，详情进入状态页。延续 PRD 家庭照片与公共屏定位。
2. 信息仪表盘：时钟、照片、天气/提示分区，信息更集中，但照片展示面积较小；当前外部数据未配置，容易出现布局空缺。
3. 图库首页：集合封面与照片网格作为入口，主动浏览效率高，但弱化无需操作的常驻展示。

建议以方向 1 为首页、方向 3 为主动浏览页面。是否采用仍待用户确认。不得因减少技术信息而隐藏 PRD 要求的 Core/NAS/连接状态或故障。

### 第 2 轮：实现 TV 核心体验

- 首页照片、时间、日期和轻量状态；增加可发现的“家庭照片 / 最近新增 / 今天拍摄”入口。
- 图库导航、清晰焦点、连续方向键与滚动、进入单图后返回原集合位置。
- 横图/竖图比例策略、加载过渡、单图信息与操作提示；具体裁切与背景处理在设计稿中确认，默认完整呈现主图。
- 统一中文与日期文案，明确“最近新增”是 Atrium 新发现，历史导入不冒充新增。
- 保持 show 暂停、refresh 保留页面、断线授权限制等已有协议语义；不默认空闲自动跳回首页覆盖用户指定照片。

退出条件：OnePlus 安装包可完整走通首页 → 集合 → 照片 → 返回；所有操作无需触摸；核心控制与断线回归通过。并完成两种目标输出尺寸的布局检查，实机远距离验收单独记录。

### 第 3 轮：家庭日用功能补齐

- 首次导入更早显示已生成照片，保留真实进度；消除长时间仅显示等待的体验。
- 面向使用者的展示设置候选：轮播间隔、时间格式、照片信息显示；落实前区分本屏与家庭全局配置，并遵守权限边界。
- 接入已有静态提示、按实际需求配置天气；自动主题和日历按需排期。
- 清晰区分网络断开、NAS 不可用和单张照片失败，并提供遥控可达的恢复动作。

其中设置界面属于原 PRD 之外的便利增强，天气/自动主题/日历为 P1，不能描述为尚未完成的基础 P0。

### 第 4 轮：迭代验收与发布准备

视觉/交互稳定后做真实电视、24 小时/7 天观察、完整性能/故障矩阵与正式签名安装包。暂停的 Mac 断电恢复、NAS 自动挂载不自动恢复执行；若维持暂停，发布说明保留相应运行条件。

## 另行排期

V0.4 home-mcp + 一个 Agent 尚未交付；AI 不是前三端闭环的欠账。语音、IoT、人物识别、家庭记忆、视频与 NAS 文件管理均不在原基础版范围，本轮不顺带加入。

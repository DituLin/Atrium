# TV「今日」与「房屋」新版界面

中文 | [English](tv-today-house-ui.en.md)

更新：2026-11-05。今日已接入 KOI 黄历并部署，OnePlus 验收通过；和风天气已完成正式配置、真实接口与 OnePlus 展示验收，详见[今日数据源与发布验证](usage/today-data.md)。下方交付表保留 2026-11-04 界面版本的历史验收记录；本次尚未完成 TCL 实机验收。

## 今日：万年历与天气

「今日」按 HTML 设计稿呈现两张主卡：横向万年历与天气。万年历使用家庭时区 `home.timezone`，显示公历日期、农历、干支、周次、年内天数、节气进度及本周七天。日期在家庭午夜换日，进入页面及休眠后回到前台也会重新核对时间。农历、干支、节气及周历现统一使用 KOI 离线表和规则；超出 1901—2099 支持范围时说明缺失。

2026-11-04 初版的宜忌保留缺失状态。2026-11-05 版本已从 `koi-almanac/1.0` 简化传统规则填入完整宜忌，并补齐月干支和来源标注；具体换年、换月和数据范围见上述数据源说明。该页面没有接入外部事项同步服务。

2026-11-04 部署版使用可选 Open-Meteo 接入。2026-11-05 和风天气适配、正式配置及实测状态，见[今日数据源与和风天气配置](usage/today-data.md)。维护者需要在 `widgets.weather` 中启用选定供应商，并设置实际位置；字段见[配置示例](../config.example.yaml)。升级界面不会自动选择城市或填入凭据。

有真实数据时，天气卡展示当前温度、最高/最低温度、湿度、风、日落、小时温度曲线及最多五天预报。天气代码采用 WMO 对照，已知英文天气描述转换为中文；未知代码或描述保留待确认状态。空气质量只有明确的 AQI 数据才显示，不从天气代码推断。缺失字段、未接入、旧数据与预报不足均有对应空态或标识，不补零、不复制示例曲线；旧版缓存缺少新增字段时仍可读取。

方向键可在万年历、天气与顶部导航间移动；在任一卡片按确定可刷新简报和天气，页面显示刷新结果并保留当前焦点。

## 房屋：固定导航与只读观测

顶部导航保持固定，仪表盘内容在内部滚动。页面按设计稿保留户型区、选中分区详情、温湿度历史与鱼缸位置，以及灯光、空调与空气、门窗与清洁分组。方向键移动到下方区域时自动滚动，使焦点保持可见。

当前六个户型分区是示意位置，明确标为「户型示意 · 房间尚未配置」，不代表真实房间或实际设备位置。真实房间几何、仪表盘设备分类、环境历史和鱼缸展示映射尚未接入；相关位置保留待配置或缺失状态，不根据设备名称、通用温度能力或单次读数推断房间、水温、室内均值与历史曲线。测试中的完整户型和曲线只使用合成资料。

已授权 Home Assistant 设备继续显示在独立的「已接入设备」只读观测区，按明确的房间关联分组；未关联设备显示为未分配房间。该区保留每项能力的真实值、可用性，以及来源变更、测量、接收和同步确认时间；未提供的时间明确说明。房屋展示映射未配置，不会隐藏已接入的真实读数。

设备卡片不发送硬件控制指令，也不会把点击绘制成操作成功。缺失、不可用、读取失败、旧观测和连接中断各自保留状态；断线时不将上次读数标为新观测或已连接。Core、当前屏幕及各照片来源的诊断与「重新检查」仍在页面下方，按各来源的有效期独立更新。HA 接入方式和授权边界见[HA IoT 部署说明](ops/ha-iot-deployment.md)。

# 首页精彩回忆与多来源照片

中文 | [English](daily-memories.en.md)

更新：2026-11-04。状态：已实现并部署，服务、浏览器及 OnePlus 实机验证通过；下方保留 11 月 2 日的历史发布证据。

## 播放与续播

首页照片区名称为“精彩回忆”。这里的“精彩”是展示名称，不包含 AI 评分、人物识别或自动精选推断。

- 每个家庭日生成一轮稳定的随机顺序，日期按 `home.timezone` 计算。每台已配对屏幕有各自的顺序与播放进度。
- 沿用每 30 秒切换一张的节奏。当天播完后按同一顺序循环，不再重新打乱。
- 返回首页、整页重载或重启应用时，从上次成功显示的照片继续。已获取、预加载或显示失败的照片不会提前推进保存进度。
- 家庭时区到午夜后开始新一轮；应用一直开着也会换日，离开首页后再回来则使用当天的轮次。
- “影像”页的普通随机合集保持原来的行为，不使用首页的每日顺序或续播进度。

续播状态保存在该屏幕浏览器的 `localStorage`，只保存屏幕标识、家庭日期及最后成功显示项的不透明游标。游标包含当前项，重新加载时会先重新获取并显示该项，再继续向后播放。它不保存图片、NAS 路径、照片 URL、凭据或整份图库。

禁用浏览器存储、清除站点数据、变更访问源站（协议、主机名或端口）或重新配对会失去续播位置；存储不可用时仍可播放。不同 TV 不同步进度。重新配对或授权失效会清除旧进度，旧游标不会恢复旧授权。

## 混合独立来源

首页默认混合当前启用且获准展示的独立照片来源。按需缓存调整后，元数据就绪且预览可生成的索引照片均可参与，缓存淘汰不会将它们移出随机池；详见[按需照片预览与小容量缓存](photo-cache.md)。来源仍分别维护自己的身份、扫描状态与撤销状态。这里不按来源分配配额；照片较多的来源可能出现得更多。相同内容若存在于两个来源，会作为两张照片处理，当前不做跨来源内容去重。

当天的稳定排序不会因新增或移除照片而将其余照片重新洗牌。新就绪的照片若排在当前位置之后，可以在当天后续播放中出现；排在之前的可能要到下一次循环或次日出现。初次历史导入同样可以进入首页与“全部照片”，但作为基线导入，不会全部计入“最近新增”。

每次取下一页或恢复播放时都会重新检查当前授权与来源状态。来源退出授权后，不再从它新取照片；保存的续播游标不构成访问许可，也不会保留其旧授权。

## 接入另一个 NAS 照片目录

每个来源授权到一个精确照片子目录，不要把整个共享目录或用户目录作为照片根目录。使用稳定、只读的 SMB 挂载，并保持 `identity.require_mount: true`、`identity.allow_local: false`，避免挂载失效后误将同名本地目录当作照片源。

以下是合成示例。向现有 `sources` 列表追加第二项，不要用片段覆盖完整配置。保留已有来源的 ID、根目录、身份及扫描设置；两个根目录不要重叠。

```yaml
sources:
  - id: source_a
    name: "Album A"
    root: "/Volumes/example-media/album-a/Photos"
    include_extensions: ["jpg", "jpeg", "png", "heic", "heif"]
    identity:
      require_mount: true
      allow_local: false
  - id: source_b
    name: "Album B"
    root: "/Volumes/example-media/album-b/Photos"
    include_extensions: ["jpg", "jpeg", "png", "heic", "heif"]
    identity:
      require_mount: true
      allow_local: false
```

维护者应先验证挂载、目录范围与读取权限，备份现有配置后追加独立来源，再按部署流程受控重启 Core。检查来源身份确认、在线状态、初次扫描和元数据就绪，并抽样验证按需预览，最后在 TV 上验证混合播放。凭据通过操作系统的挂载机制管理，不写入公开配置示例或文档。原片保持只读，索引、数据库与生成的预览留在本机磁盘。

新增来源不会自动扩展 integration 的来源 allowlist；如其他集成也需要访问，必须另行明确授权。不要为了接入新相册重置现有来源身份、清空图库索引或放宽挂载检查。

## 接口与交付边界

首页使用经过屏幕身份认证的 `GET /api/v1/photos/memories`。服务端按家庭日、屏幕与照片标识计算稳定顺序，使用游标分页；恢复请求重新检查当前可见照片，不复用旧的授权结果。不需要数据库结构迁移。

本次发布版本、测试结果、来源接入与实机验证应单独留证；本说明不替代发布验收，也不承诺所有照片在一天内都能播完。
